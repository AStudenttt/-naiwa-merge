## 关于奶蛙

相传天地初开，世间尚无奶蛙。直到某日，一声大笑自云外传来，一团黄色之物坠入人间，落地时肚皮朝上，两眼望天。众人不知其为何物，见它似龙非龙，似蛙非蛙，便称其为“奶蛙”。

奶蛙不食五谷，不修仙法，平日只是大笑。两只相同的奶蛙若撞在一起，便会化为一只更大的奶蛙。古人以为这是祥瑞，直到院子里装不下了。

于是，人们造出一个容器，试图合成传说中的大奶蛙。你眼前的，便是此物。

## 小奶蛙，大麻烦

将奶蛙投入容器，相同等级的两只奶蛙碰撞后会合成更大的一只。共有 11 个等级，试着提高分数，同时控制越来越拥挤的奶蛙堆。

奶蛙会弹跳、晃动，也会在被挤压时露出不太体面的表情。

## 怎么玩

- **触屏：** 拖动选择位置，松手掉落。
- **键盘：** 方向键移动，空格键掉落。
- **合成：** 让相同等级的两只奶蛙碰到一起。
- **注意警戒线：** 奶蛙持续碰线会触发倒计时。

打开图鉴，可以查看各级奶蛙，以及它们被压住时的样子。

## 打开就能玩
